## О проекте

Консольное приложение для учёта семейного бюджета. Позволяет вести счета, доходы и расходы семьи, настраивать регулярные платежи, разделять права между Главой семьи и членами семьи, получать отчёты.

Приложение построено по многослойной архитектуре: модели данных, репозитории (работа с SQLite), сервисы (бизнес-логика) и консольный интерфейс. SQL-запросы находятся только в репозиториях, интерфейс обращается только к сервисам.

## База данных

Пять таблиц (см. ER-диаграмму ниже): `users`, `accounts`, `categories`, `regular_payments`, `transactions`. Схема и тестовые данные лежат в `schema.sql`. Для каждой таблицы реализованы модель (`dataclass`), репозиторий с CRUD и сервис.

## Функционал

- Авторизация и регистрация пользователей, пароли хранятся в виде хеша (PBKDF2)
- Разграничение ролей: **Глава** и **Член семьи**
- **Счета** с балансом и валютой
- **Транзакции** (доходы и расходы) с привязкой к счёту, способом оплаты (наличные/карта); баланс счёта пересчитывается автоматически при добавлении, изменении и удалении
- **Категории и подкатегории** (один уровень вложенности)
- **Регулярные платежи** (раз в месяц или неделю) с проведением платежа как обычной транзакции
- Управление **членами семьи** (Глава)
- Отчёт: доходы, расходы, остаток на счетах, суммы по категориям

### Бизнес-правила

- сумма больше нуля, дата в формате `ГГГГ-ММ-ДД`, существование категории, счёта и пользователя
- расход не может превысить остаток на счёте; нельзя удалить доход, если баланс станет отрицательным
- тип подкатегории совпадает с типом родительской категории
- нельзя удалить категорию, счёт или пользователя, на которые есть ссылки
- нельзя удалить или разжаловать последнего Главу семьи
- проверка уникальности логина, названий категорий и счетов владельца

## Роли и права

| Действие | Глава | Член семьи |
|---|---|---|
| Просмотр транзакций, счетов, регулярных платежей | всех | только своих |
| Добавление транзакций | по своим счетам | по своим счетам |
| Изменение и удаление транзакций | любых | только своих |
| Управление счетами | любыми | только своими |
| Управление категориями | да | только просмотр |
| Управление членами семьи | да | нет |
| Отчёт | по всей семье | по своим данным |

## Запуск

```
cd src/family_budget
python main.py
```

На Windows, если команда `python` не работает, используйте `py main.py`. Требуется Python 3.10 или новее.

База данных `family_budget.db` создаётся автоматически из `schema.sql` при первом запуске. Чтобы вернуть тестовые данные, удалите файл `family_budget.db` и запустите программу снова.

```

```

Тесты слоя сервисов находятся в `tests/test_layers.py`: авторизация, права по ролям, валидация данных, пересчёт баланса счетов, подкатегории, регулярные платежи, отчёты.
